# Brass Signal

Brass Signal is an original 3D railway dispatch game. Throw the two switches and match the symbol on each locomotive to its station. The first lever sends trains to Fern or to the second switch. The second lever selects Honey or Poppy. Press 1 or 2 on a keyboard, or tap the matching lever. Earn stars to open five shifts.

Open the self-contained index.html in a WebGL browser. The game also runs when served from a static host. The source entry is index-source.html. Run build.py with Python 3 to refresh both self-contained entries and the root-entry ZIP.

Progress, settings, and an in-flight timetable are saved under brass-signal-v1. The optional GameWave adapter uses only the brass-signal profile envelope. A confirmed like unlocks a brass headlamp, and a confirmed direct comment unlocks the conductor’s gold cap. The cloud stores ratings and cosmetic flags. The in-flight timetable stays on the current browser.

Run node core-tests.mjs and node sdk-tests.mjs for routing, progression, checkpoints, and mocked SDK behavior. The graphics, sound effects, and music are original. The bundled Three.js library is distributed under the MIT License in vendor/THREE-LICENSE.txt.
